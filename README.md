# 3D Neon Loading Animation

A sleek, modern, and lightweight loading animation built using pure HTML and CSS. Featuring 3D transformations and a vibrant neon glow, this component is designed to add a polished touch to modern web applications.

## ✨ Features

* **Pure CSS Animations:** Smooth 3D rotation effects powered by CSS keyframes without any JavaScript dependencies.
* **Neon Aesthetic:** Eye-catching cyan border styling with custom outer and inner box-shadow glows against a deep dark background.
* **Lightweight & Fast:** Minimalist structure consisting of just a single HTML file and a CSS stylesheet.

└── css/
    └── style.css    # Styling, layout centering, and 3D animation keyframes

## 🚀 Getting Started

To view or run this project locally, simply follow these steps:

1. Clone or download this repository to your local machine.
2. Ensure your project folder structure matches the file layout above.
3. Open `index.html` in any modern web browser.

## 🛠️ Customization

You can easily customize the animation and appearance by modifying `css/style.css`:

* **Colors:** Change the `#10F2F0` hex code to match your preferred theme color.
* **Speed:** Adjust the animation duration in the `.loading-box` rule (`animation: loading 2s infinite ease-in-out;`).
